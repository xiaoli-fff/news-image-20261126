A one-page newspaper front page for Thursday, 26 November 2026, packing 37 stories into a single 1024×1024 image. The lead story is Trump's new tariffs on 14 partners, with a small chart of the proposed rates, and the grid below covers the burning tankers in Hormuz, the probe into Shanghai's party chief, the first foreign astronaut aboard China's space station, Nvidia's downgrade watch, SpaceX's million-satellite approval, and the Dow closing above 50,000. Every story carries a region tag and a colour-coded accent bar, so the whole day's news reads at a glance.

## Run it

```sh
python3 main.py
```

The program copies the bundled entry.png into MAKEFUN_OUTPUT_DIR (default /output/entry.png).

To redraw the front page from scratch, run `python3 draw_collage.py` first — it regenerates entry.png in this directory.
